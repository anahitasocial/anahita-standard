Its web app is [anahitasocial/anahita-web](https://github.com/anahitasocial/anahita-web), and [anahitasocial/anahita-services](https://github.com/anahitasocial/anahita-services) is to be published shortly. Read more at [www.anahita.io](https://www.anahita.io).
>
> Thank you to everyone who built, ran and used Anahita in PHP since 2010.



# Anahita Standard

Anahita Standard provides a standard installation of Anahita. It also provides an empty skeleton and some example components to help you get started in building your first Anahita app.

To get started with Anahita please follow the instruction at [Anahita Readme](https://github.com/anahitasocial/anahita/blob/master/README.md)
